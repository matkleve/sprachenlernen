### What an audit of that work found before it landed

Four things, fixed in the same change rather than filed:

1. **The spec's own acceptance criterion was false.** `back !== lemma` failed
   for six cognates, and *no test enforced any of the five new criteria* — the
   AC file was prose. Now: six tests, shown red against the original deck.
   The criterion itself was the wrong shape — a true cognate satisfies its
   intent and violates its letter — so the exceptions are listed as data in
   `es-meaning-recall.cognates.json`, read by both the script and the test.
2. **Machine glosses shipped as dictionary sense lines.** `perro` was *"dog (the
   species Canis familiaris (sometimes designated…"*; `amor` was *"a surname"*.
   Mean back length 22.7 → 11.0 chars. Shaping is mechanical (drop apparatus,
   first sense group, ≤3 synonyms, ≤60 chars) and applies to Kaikki only —
   overrides ship verbatim, because shaping a reviewed answer undoes the review.
   A gloss that fails shaping now **fails the build** naming the lemma.
3. **Proper names and lemmatiser artefacts were in the pool** — `john`, `jack`
   and `afuerar` (not a Spanish verb), the last of which had been given a
   hand-written gloss rather than removed. Now
   `es-meaning-recall.exclusions.json`, applied *before* the cap so the pool
   stays 500 and reaches one rank deeper instead.
4. **A 10× pool changed two surfaces the PR did not touch.** `/words` rendered
   the atlas unpaginated — 500 rows. Capped at 100, with both numbers named.
   And `listReviewsForTaskIds` sent the whole pool through PostgREST's
   `in.(…)`, which rides in the query string: **~13 KB raw, ~19 KB encoded**,
   past a typical gateway's request-line limit. Batched at 100 and re-sorted
   across batches, because `rebuild` is order-dependent.

**The trap worth keeping** (and now in `TRAPS.md`): every test around that query
stubs the client, so the gate stayed green at any pool size. Growing a data file
is not a data-only change — it is a change to every query that spans the file.

5,000-form frequency list resolves to. Stage 2 fits; stage 3 needs a bigger
list, which is a provenance and recalibration event, not a script change.

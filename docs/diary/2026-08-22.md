## Breakthrough — photographic wood FFT at native crack scale

Owner reaction on the sharp wood-01 remake: *"Omg this is so close"* — treated as
a **major breakthrough** for progression Workshop materials.

**Root cause of bubbly cracks (diagnosed this session):** `FEATURE_SCALE=9.0`
in `wood-grain-fourier-synthesis.py` blew the crack spectrum ~9× wider in pixel
space. Heeger–Bergen + `SPEC_SMOOTH_SIGMA` already soften edges; at scale 9 the
result is fat dark blobs with puffy rim halos, not fine checking lines. Profile
slice on wood-01: real cracks = narrow spikes; scale 9 = broad humps.

**Fix shipped:** `FEATURE_SCALE` default **9.0 → 1.0** (native size measured
from the source photo). Reference tile saved as
`design/progression/breakthrough-wood-01-final.png`.

**Assets landed (from `cursor/wood-patch-pipeline-948e`):**

- `design/progression/source-grid-wood-upload.png` — owner 3×2 grid
- `design/progression/patches/wood-01.png` … `wood-06.png` — one species each
- `design/progression/synthesized/` — recipe outputs per patch
- `scripts/slice-wood-texture-grid.py`, `scripts/fft-crack-layer-analysis.py`,
  `scripts/wood-synthesis-comparison.py`

**Height-field valley model (owner correction):** Cracks are grooves in relief —
dark = valley, light = ridge — not Gaussian blur residuals. Rewrote defect
extraction in `wood-grain-fourier-synthesis.py`: vertical ridge envelope via
`grey_dilation`, fine + coarse valley depth bands, sharpen before composite.
Rejected `relu(blur_22 − blur_6)` coarse layer (blobby, wrong physics). All six
patches re-synthesized on `cursor/coarse-crack-layer-f642`.

**texture-metrics (wood-01 vs board, full frame):** contrast −0.48, lightRange
−0.49, tone −0.44 — fine checking improved structurally but bright wash / wide
fissures still under target (board p95 L 0.93 vs synth 0.46). Next: coarse
strength/radius tuning, highlight lift in composite.

**Still not done:** knots (wood-05/06) fail structurally; OKLCH colour ramp vs
albedo-multiply open.

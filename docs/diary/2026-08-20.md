## Security audit — ten findings, all fixed (2026-08-20)

**Change class: Sensitive** (auth, deletion, persisted data). Red-test-first on
every finding with a code path; full `verify` green, justified by
VERIFY-SCOPES.md ("auth, DB, or persisted data paths touched").

unnoticed.

1. **`deleteAccount` trusted the session cookie.** Fixed with `getVerifiedAccount()`.
2. **Open redirect** in `/auth/callback` — Fixed with `safeInternalPath`.
3. **CI handed the service-role key to every `pull_request` run** — Split into
   environment-gated job.
4. **BACKEND.md §8 gates were prose.** `scripts/check-secrets.mjs` now in default scope.
5. **No security headers at all.** ADR-0013.
6. `create-test-user.ts` → `scripts/`, env-supplied, refuses production.
7. `task_state` update filtered on `task_id` only.
8. `content_sources.body` ceiling added (100 000).
9. "Complete archive" expanded per UC-024.
10. `/login?error=` — codes resolved from `messages/*.json`.

New traps recorded: `getSession()` verifies nothing; `startsWith("/")` is not a
path check.

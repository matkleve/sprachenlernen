# 2026-08-12 — Engine #2 slice 1: form-recall pool

**Change class: Standard.** Spec first (`form-recall-pool.md`), then pool + staging.

Lemma tables were already tier B (2026-08-08). This slice wires **form-recall**
into the card engine:

- `data/starter/es-form-recall.json` — 406 cards (94 lemmas have no inflected
  form distinct from the lemma, e.g. `el`)
- `scripts/build-form-recall-pool.mjs` — picks highest-frequency form per lemma,
  preferring `ind.pres.*` over gerund/participle
- `lib/form-recall-pool.ts`, `lib/form-recall-staging.ts` — load + gate: form-recall
  enters scheduling only when meaning-recall for the same `wordId` is **held**
- `poolForScheduling` concatenates meaning + form pools

**Not in this slice:** form-mastery signal on Progress, UI distinction on the
card face, Italian, paradigm-table method.

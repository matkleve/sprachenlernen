# UC-058 — Do it anyway, when the app says wait

<!-- id: UC-058 -->
<!-- specs:  -->

**Who:** a learner who has read "this works better later" and wants to do it now
regardless.
**Wants to:** start the method without arguing with the app, and without being
quietly given something easier instead.
**So that:** the app's judgement stays advice, which is the only status it has
earned.

Derived from the same **[D — user decision, 2026-08-08]** as UC-057: *"it's not a
hard order — soft block, you can still do it if you click on it."* Constrained by
[`../study/02-evidence.md`](../study/02-evidence.md) E7 (a structure that cannot
be declined is controlling) and UC-047.

## Today

Locks. Either the content is unavailable, or the app permits it after a warning
dialogue that treats the learner as a risk. Both teach the learner that the
app's model of them outranks their own judgement — and the app's model is an
estimate with a wide band.

## Success looks like

- One tap starts a "better later" method. No confirmation dialogue, no second
  ask, no "are you sure", no tally of overrides.
- What the learner gets is the method they asked for, at the closest difficulty
  the app can actually build — and the card said which that was **before** the
  tap, not after.
- The app never silently substitutes an easier variant because it expected the
  learner to struggle (UC-047), and never silently substitutes a harder one
  because they overrode.
- Struggling inside it is not treated as having been warned. No "as we
  mentioned", no retrospective vindication, nothing that reads as a lesson.
- The session's results count normally — toward the same signals, with the same
  weight, feeding the same cards.
- Afterwards, the one existing rating follow-up applies unchanged: "too hard"
  makes the **material** easier, not the method rarer
  ([12](../study/12-method-cards.md)).
- If the learner overrides the same readiness judgement repeatedly and the
  sessions go well, that is evidence about the **judgement**, and the app treats
  it as such rather than as a habit to correct.

## Out of scope

A separate "advanced" or "expert" mode, any warning interstitial, and readiness
overrides for the "no material yet" state — there is nothing to start there, so
there is nothing to override. That is UC-059.

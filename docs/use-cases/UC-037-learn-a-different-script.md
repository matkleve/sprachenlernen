# UC-037 — Learn a language written in a different script

<!-- id: UC-037 -->
<!-- specs:  -->

**Who:** a learner starting Greek, Russian, Arabic, Japanese or Chinese.
**Wants to:** learn the writing system as part of the language rather than as a
prerequisite they must survive alone.
**So that:** the script stops being the wall that ends the attempt in week two.

Derived from
[`../study/STUDY-016-language-kit.md`](../study/STUDY-016-language-kit.md) U2 and
[`../study/STUDY-007-offline-and-paper.md`](../study/STUDY-007-offline-and-paper.md).

## Today

Apps either assume the Latin alphabet or bolt on a separate alphabet course that
is finished and forgotten before the language starts. Typing is assumed to be
possible. Where a script is not written the way it is read — unwritten vowels in
Arabic, three systems in Japanese — the model breaks entirely.

## Success looks like

- Script is a declared property of the language, and everything downstream reads
  it: input method, card types, typography, whether handwriting practice is
  offered.
- Answering a card never requires typing in an unfamiliar script. Selecting or
  speaking counts equally (UC-021).
- Handwriting practice is offered first and most prominently here, because this
  is where the evidence for the motor trace is strongest — the stroke is part of
  what is being learned, not a study preference.
- For languages written without word boundaries, the app states that its coverage
  figure depends on a segmentation model, and treats that as an accuracy limit
  rather than hiding it.
- Where a script omits information present in speech, reading and listening are
  tracked as clearly separate skills, because knowing the word and being able to
  read it are further apart than in a Latin-script language.

## Out of scope

Calligraphy, stroke-order grading, and character etymology as a subject.

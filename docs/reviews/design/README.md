# Design reviews

UX designer and owner review documents. **Not studies, not specs.**

Normative behaviour lives in [`docs/specs/`](../../specs/). These files record
problem statements, designer verdicts, and owner decisions that informed specs.

Format: [`DR-NNN-slug.md`](../../reviews/design/DR-028-mobile-desktop-layout.md) with
`<!-- id: DR-NNN -->` and `<!-- type: design-review -->`.

Old paths under `docs/study/` are listed in
[`study/MIGRATION-MAP.md`](../../study/MIGRATION-MAP.md).

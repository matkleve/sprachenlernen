# Method material setup — acceptance criteria

Split child of [`method-material-setup.md`](method-material-setup.md).

- [ ] AC-1 · Given `extensive-reading` with all three modes, when detail renders,
      then the setup panel shows app pick, topic, and own-material options.
- [ ] AC-2 · Given `srs-session`, when detail renders, then no setup panel appears.
- [ ] AC-3 · Given topic mode with a matching catalogue Source at 93 %, when the
      match line renders, then coverage is shown as text and Start is enabled.
- [ ] AC-4 · Given pasted text at 78 % with learner mode, when preview renders,
      then demanding band copy appears before Start is enabled.
- [ ] AC-5 · Given keep unchecked, when the session ends, then no new row appears
      on `/content`.
- [ ] AC-6 · Given keep checked, when Start succeeds, then a `learner` Source is
      listed on `/content`.
